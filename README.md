Если вы уверенно настраиваете исключения, лучше добавить исключение; если не вполне понимаете свои действия, рекомендуется отключить обнаружение PUA.

## ⚙️Использование

1. Активируйте Безопасный DNS (Secure DNS)
    * В Chrome включите «Использовать безопасный DNS» и укажите поставщика DNS, отличного от варианта «Поставщик по умолчанию»
    * В Firefox откройте «DNS через HTTPS», установите режим «Персональный», затем нажмите «Выбрать провайдера/поставщика» и вручную задайте URL. Например, подойдёт `https://dns.google/dns-query`, поскольку Cloudflare может оказаться заблокирован
    * Windows 11 позволяет включить Secure DNS непосредственно в параметрах системы — [инструкция находится здесь](https://remontka.pro/dns-over-https-windows-11/). Этот способ рекомендуется пользователям Windows 11
    * На роутере Keenetic активируйте параметр «Транзит запросов». Если он выключен, при настройке и работе Secure DNS на компьютере могут возникнуть проблемы

2. Загрузите архив (zip/rar) со [страницы актуального релиза](https://github.com/ShipwrightSurvive/zapret-discord-youtube/releases/latest)

3. Откройте свойства загруженного архива и отметьте пункт «Разблокировать». Пользователям 7-Zip или PeaZip выполнять этот шаг не требуется

4. Извлеките архив в каталог, путь к которому не включает кириллицу и специальные символы

5. Откройте требуемый файл
    * Чтобы определить рабочую стратегию: **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`
    * Чтобы включить автозапуск: **`service.bat`** -> `Install Service` -> *выберите подходящую стратегию*

## ℹ️Что делают файлы

- [**`general.bat ...`**](./general.bat) — ручной запуск стратегии

  Ручной режим позволяет проверить, работает ли выбранная стратегия. Результат зависит от множества условий. **Перебирайте стратегии (ALT, FAKE и остальные), пока не обнаружите подходящий для себя вариант**

- [**`service.bat`**](./service.bat) — управление автозапуском и дополнительные возможности:
  - <ins>**`Install Service`** — добавление выбранной стратегии в автозапуск (services.msc)</ins>
  - **`Remove Services`** — удаление стратегии и WinDivert из списка служб
  - **`Check Status`** — просмотр состояния обхода и служб: стратегии в автозапуске и WinDivert
  - **`Game Filter`** — изменение режима обхода для игр и других сервисов, работающих по UDP и TCP на портах выше 1023.  
  **После изменения параметра перезапустите стратегию.**  
  Текущее состояние — включено или выключено — отображается в скобках.
  - **`IPSet Filter`** — выбор режима обхода ресурсов, перечисленных в `ipset-all.txt`.  
  Этот параметр пригодится при проверке ресурса, который открывается без zapret, но не работает вместе с ним  
  В скобках показывается активный режим:
    - `none` — проверка не применяется ни к одному IP
    - `loaded` — IP сверяется со списком
    - `any` — фильтрация распространяется на любой IP  
  - **`Auto-Update Check`** — включение или отключение автоматического поиска обновлений
  - **`Replace active fakes`** — замена указанного активного фейка другим файлом из каталога `bin`
  - **`Update IPSet List`** — загрузка актуального списка `ipset-all.txt` из репозитория
  - **`Update Hosts File`** — обновление hosts <ins>**для восстановления веб-версии Telegram и соединения с голосовым чатом Discord**</ins>
  - **`Check for Updates`** — ручной поиск обновлений
  - **`Run Diagnostics`** — поиск типичных причин, из-за которых zapret может не запускаться или не работать.  
  В завершение можно удалить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`: это иногда помогает, когда приложение внезапно перестаёт подключаться
  - **`Run Tests`** — открытие инструмента для тестирования стратегий:
    - `Standard tests` — проверка ресурсов, перечисленных в `utils/targets.txt`
    - `DPI checkers` — диагностика DPI через разных провайдеров, включая Cloudflare и Amazon


## ☑️Частые вопросы и неполадки

### Скрипт `general*` запускается, но ничего не происходит

- При ручном запуске стратегии отдельным bat-файлом, а не через service, должен открыться процесс winws.exe, отвечающий за обход; его видно на панели задач.  
Если окно не появилось, обратитесь к [#522](https://github.com/ShipwrightSurvive/zapret-discord-youtube/issues/522)

### Не удаётся подобрать рабочую стратегию
- Откройте командную строку с правами администратора
- По очереди выполните следующие команды:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`
  
- Перезапустите компьютер

### Не открывается веб-версия Telegram
Откройте **`service.bat`** и выберите **`Update hosts file`**. Если текущий hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте всё содержимое появившегося окна Блокнота
  - В показанной папке найдите `hosts` и откройте его текстовым редактором, запущенным от администратора
  - Вставьте скопированный текст в конец `hosts` либо замените ранее добавленный аналогичный блок
  - Сохраните изменения и снова проверьте соединение. Если результата нет, убедитесь, что файл `hosts` действительно был сохранён.

#### Работоспособность этого способа не гарантируется. Если он не помог, установите [Desktop-версию](https://github.com/telegramdesktop/tdesktop/releases) и используйте [локальный прокси](https://github.com/ShipwrightSurvive/tg-ws-proxy) либо любой публичный.

### Обход перестал работать или не работает изначально

> [!IMPORTANT]
> **Со временем отдельные стратегии могут утрачивать работоспособность.**
> Некоторый вариант способен работать определённый период, а затем перестать из-за обнаружения.
> Репозиторий содержит много разных стратегий обхода. Если ни одна не подходит, создайте собственную на базе представленного варианта, изменив его параметры.
> Описание параметров стратегий доступно [по этой ссылке](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Запустите `service.bat` -> `Run Diagnostics` и проверьте, отсутствуют ли ошибки

- Удостоверьтесь, что адрес нужного ресурса добавлен в перечень доменов или IP

- Переберите остальные стратегии, включая **`ALT`**, **`FAKE`** и другие

- Выполните полную переустановку по инструкции из следующего раздела

- Дополнительные сведения приведены в [#765](https://github.com/ShipwrightSurvive/zapret-discord-youtube/issues/765)

### Как начисто обновить или переустановить программу?
- Сделайте резервную копию ресурсов и данных, добавленных вами вручную
- Перезагрузите устройство
- Выполните `service.bat` -> `Remove Services`
- Откройте `service.bat` -> `Run Diagnostics`, устраните найденные ошибки и в конце выберите Y
- Удалите каталог с zapret
- Загрузите свежую версию [на странице релизов](https://github.com/ShipwrightSurvive/zapret-discord-youtube/releases), выбрав архив `zapret-discord-youtube-...`
- Щёлкните по архиву правой кнопкой мыши и откройте свойства. Если справа внизу доступна отметка «Разблокировать», установите её, затем нажмите «Применить» и «ОК»
- Извлеките файлы в новую папку в корне диска, избегая пробелов и специальных символов в пути
- Поочерёдно запускайте разные скрипты `general`, то есть стратегии, и проверяйте доступность интернет-ресурсов. Если они не открываются, завершите программу через значок замка на панели задач и перейдите к следующей стратегии
- Обнаружив рабочий вариант, добавьте его в автозапуск: `service.bat` -> `Install Service` -> выберите нужную стратегию

### При включённом zapret перестаёт работать игра или приложение

- Убедитесь, что в service.bat для `Game Filter` установлено **`disabled`**, а для `IPSet Filter` — **`none`**. Другие значения могут неожиданно повлиять на доступность сторонних ресурсов.

### Античит обнаруживает WinDivert

- Следуйте инструкции по адресу https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Windows 7 требует цифровую подпись драйвера WinDivert

- В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### После удаления через [**`service.bat`**](./service.bat) служба WinDivert не исчезает

1. Определите имя службы, выполнив в командной строке Windows (Win+R, `cmd`) команду:

```cmd
driverquery | find "Divert"
```

2. Затем остановите службу и удалите её следующими командами:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не открывается <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте правильность настройки [Secure DNS](#%EF%B8%8Fиспользование)
- Выключите блокировщик рекламы: известно, что YouTube начал противодействовать таким расширениям.
- Переберите остальные стратегии, особенно если прежняя недавно перестала работать.
- Дополнительные рекомендации доступны в [#251](https://github.com/ShipwrightSurvive/zapret-discord-youtube/discussions/251)

### Не подключается <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Удостоверьтесь, что [Secure DNS](#%EF%B8%8Fиспользование) настроен
- Сначала желательно определить стратегию, при которой загружается YouTube, и запустить именно её.
- Откройте `service.bat` -> `Run Diagnostics` и согласитесь на очистку кэша Discord.
- Перезапустите приложение Discord и проверьте, помогло ли удаление кэша.
- Откройте Discord в браузере по адресу https://discord.com/app. Если веб-версия работает, можно временно пользоваться ею.
- Если подключение отсутствует и в браузере, снова проверьте каждую стратегию. Иногда YouTube открывается с выбранной стратегией, а Discord — нет.
- Больше информации есть в [#252](https://github.com/ShipwrightSurvive/zapret-discord-youtube/discussions/252)

### Не подключается <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Воспользуйтесь приложением [tg-ws-proxy](https://github.com/ShipwrightSurvive/tg-ws-proxy)
- Другой вариант — бесплатные публичные MTProto-прокси из интернета

### Игры не подключаются

Игр существует слишком много, поэтому исследовать и исправлять работу каждой отдельно невозможно.

Наиболее универсальная последовательность действий:
- обновите ipset через `service.bat`, после чего активируйте `Game Filter`
- если результата нет, дополнительно попробуйте режим `ipset any`

Учтите, что `ipset any` может нарушить доступ ко многим сайтам. Не оставляйте этот режим включённым постоянно: вместо этого определите все IP-адреса, к которым обращается игра, и внесите их в `ipset-all.txt`

Если эти действия не помогли, откройте тему в разделе [Discussions](https://github.com/ShipwrightSurvive/zapret-discord-youtube/discussions), а не в issues, и дождитесь советов других игроков.

## 🗒️Как добавить адреса других ресурсов

Дополнительные адреса для обхода вносятся в следующие файлы:
- **`list-general-user.txt`** — домены; их поддомены будут учтены автоматически
- **`list-exclude-user.txt`** — исключения доменов, например когда IP-сеть присутствует в `ipset-all.txt`, но отдельный домен внутри неё фильтровать не нужно
- **`ipset-all.txt`** — IP-адреса и подсети
- **`ipset-exclude-user.txt`** — исключаемые IP-адреса и подсети
  - Файлы вида **`*-user.txt`** будут созданы автоматически при первом открытии `zapret` или `service.bat`
